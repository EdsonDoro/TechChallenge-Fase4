# Notebooks

Os notebooks devem documentar a jornada experimental e reprodutível:

1. `01_exploracao_olist.ipynb` — entendimento da base e seleção das avaliações.
2. `02_preparacao_base.ipynb` — limpeza, nulos, documentos e metadados.
3. `03_embeddings_indexacao.ipynb` — embeddings e índice vetorial.
4. `04_avaliacao_rag.ipynb` — perguntas, recuperação, evidências e avaliação.

As implementações definitivas devem permanecer em `src/`, enquanto os notebooks servem como documentação executável da jornada.
